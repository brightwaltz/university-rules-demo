例題で確かめる（業務担当者向け）

AI が規程の本文から作った例題と、境界値の例題です。
各例題の『状況』と『結論』を見て、業務として正しいかを選んでください。Horn 節を読む必要はありません。
確認済みの例題は、以後の自動テストでシステムの判定と照合されます。

システムの判定は、data/examples.yaml の例題を Python 版の処理系で評価した結果を埋め込んだものです。 入力した判断はこのブラウザの localStorage にのみ保存されます。「確認結果を書き出す」で JSON にして python scripts/import_reviews.py で取り込んでください。
