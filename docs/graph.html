オントロジーグラフ

語彙の構造を node / edge / hypernode で表したグラフ文書（data/ontology_graph.yaml）を可視化・編集します。 hypernode は階層（語彙レイヤ・業務領域）と、メタ知識（なぜその用語を選んだか）の両方を表します。 編集結果は同じ形式で書き出せるので、リポジトリへ戻せます。

    この文書について

    導出エッジ（破線・鍵アイコン）は rule_terms や close_match から 自動生成されるため編集できません。元の属性を直すと変わります。

    ノードまたはエッジを選択してください。

    グラフ文書の形式

    AI にも人にも読み書きしやすいことを狙って、次の3要素だけで構成しています。 1つの事実は1箇所にだけ書き、導出できる関係は書きません。

    要素役割主なキー
    nodes単一の対象。概念・語彙の用語・ルール種別・語彙そのもの id, kind, label, curie, term_kind, comment, close_match
    edges有向の関係。端点には hypernode も取れる source, target, kind, label
    hypernodesメンバーを持つノード。入れ子にできる id, kind, label, members, about, statement, evidence

    members が階層構造を、about ＋ statement がメタ知識を表します。 参照整合性と入れ子の循環は、この画面と src/graph_document.py の両方で検査します。
